# 데이터 계보·산출 기준 UI 설계

## 목적

모든 분석 페이지에서 사용자가 차트의 원자료, API명, 원필드, 집계 방식과 기관 발표치와의 차이를 즉시 확인할 수 있게 한다.

## 표시 구조

- 각 차트 바로 아래에 작은 회색 글씨로 `SOURCE · 원자료 · 가공`을 표시한다.
- 각 페이지 상단에는 기본 접힘 상태의 `데이터·산출 기준` 토글을 둔다.
- 사이드바의 가이드북은 페이지별 사용 데이터와 산식, 매핑 흐름, 기관별 수치 차이를 기능별 토글로 제공한다.

## 데이터 계보

- 관세청 수출: `관세청_품목별 수출입실적(GW)`, `getItemtradeList`, `expDlr`.
- 국가별 수출: `관세청_국가별 수출입실적(GW)`, `getNationtradeList`, `expDlr`.
- 품목·국가 수출: `관세청_품목별 국가별 수출입실적(GW)`, `getNitemtradeList`, `expDlr`.
- 실물지표: KOSIS 광업제조업동향 통계표 `DT_1F02001`, 생산·출하·재고 지수.
- 품목분류: 관세청 HS10, KITA HSK-MTI 연계, 산업부 20대 수출품목, 자체 리서치 중·소분류.
- 최근 수출: 관세청·산업통상자원부의 월중 및 월간 수출입 동향.

## 핵심 산식

- Top20 수출액은 월·HS10별 `expDlr`를 고정 택소노미와 내부결합한 뒤 Top20별 합산한다. 미매핑 HS10은 Top20 수치에서 제외한다.
- 억달러는 USD 합계 ÷ 100,000,000이다.
- YoY는 전년 동월 대비, MoM은 전월 대비다.
- 구간 초→말 3M 성장률은 첫 3개월 월평균과 마지막 3개월 월평균을 비교한다.
- 동일기간 성장률은 선택기간 합계와 직전 동일 길이 기간 합계를 비교한다.
- 재고순환은 출하 YoY − 재고 YoY다.

## 기관 발표치 관계

산업부는 월초 잠정 총계와 정책 품목 기준, 관세청 API는 통관신고 기반 상세·현행화 자료, K-stat은 관세청 무역통계의 조회·분류 서비스다. 대시보드는 관세청 HS10 상세자료를 2026 고정 택소노미로 재집계하므로 공표 시점, 잠정·확정 상태, 분류 범위, 미매핑 품목에 따라 산업부·K-stat과 차이가 날 수 있음을 명시한다. KOSIS 실물지표는 수출액에 합산하지 않고 산업 연결표를 통해 비교·점수화한다.

## 구현

- `data_lineage.py`에 출처 메타데이터와 페이지별 산출 기준을 중앙화한다.
- `render_chart`가 출처 키를 받아 차트 바로 아래에 캡션을 출력한다.
- 각 렌더링 함수가 페이지 기준 토글을 출력하고 차트별 출처 키를 전달한다.
- 가이드북은 같은 메타데이터와 산식 문구를 재사용한다.

## 검증

- 출처 메타데이터에 기관·API·원필드·링크·가공 설명이 있는지 검사한다.
- 수출 성장 산식 문구가 실제 코드의 두 계산 모드와 일치하는지 검사한다.
- 모든 `render_chart` 호출에 출처 키가 지정됐는지 정적 검증한다.
- 전체 테스트와 Python 컴파일, Streamlit 기동을 확인한다.
